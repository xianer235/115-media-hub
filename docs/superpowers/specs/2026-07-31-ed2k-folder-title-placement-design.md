# ED2K 文件夹标题选词区布局调整

## 目标

将 ED2K 文件夹标题选词区从资源与文件选择列移动到保存设置列，使操作顺序与实际保存路径的形成过程一致，同时保持现有选词、编辑和文件选择行为不变。

## 界面结构

ED2K 导入弹窗左侧只保留资源概览、解析状态和文件选择列表。右侧保存设置按以下顺序排列：

1. 父保存目录与常用目录。
2. “新建文件夹”开关。
3. 文件夹标题选词区。
4. 文件夹名称输入框与重新选词按钮。
5. 最终提交路径与监控信息。

标题选词区继续使用现有样式和交互，不新增卡片或二级弹窗。它作为文件夹创建区域的内部子区块显示，避免形成卡片嵌套。

## 状态行为

- ED2K 外链解析完成后，标题选词区在新位置默认展开且不预选。
- 完成选词后，标题选词区收起，结果写入文件夹名称输入框。
- 点击文件夹名称旁的重新选词按钮时，标题选词区在右侧保存设置中重新展开，并滚动到该区域。
- 关闭“新建文件夹”时隐藏标题选词区，文件夹名称输入框和重新选词按钮沿用现有禁用行为，文件直接保存到已选父目录。
- 重新开启“新建文件夹”时恢复关闭前的标题选词状态和文件夹名称。
- 解析失败或仍在解析时，标题选词区保持隐藏；解析状态继续显示在左侧 ED2K 文件区域。

## 响应式布局

桌面端标题选词区位于右侧保存设置列。移动端沿用现有单列顺序：资源概览、文件列表、保存设置；标题选词区随保存设置出现，不产生横向滚动。
