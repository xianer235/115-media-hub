# 刮削识别完整路径选词设计

## 目标

将刮削管理“识别与命名”面板中的整段推荐关键词按钮替换为大爆炸选词区。选词原文来自所选资源的完整文件夹路径，用户通过点击或连续滑动选择词块，再将组合结果填入 TMDB 搜索框。

该交互与 ED2K 文件夹标题选词保持相同的分词、选中和拼接规则，但刮削面板仍保留现有 TMDB 类型选择、手工编辑、搜索与绑定流程。

## 通用模块

从现有 `ResourceEd2kImport` 中提取与 ED2K 无关的纯文本选择能力，形成应用级通用工具模块。通用模块负责：

- 中文按单字拆分；英文和数字按点号拆分，使用下划线或短横线连接的连续内容保留为词块。
- 根据起点、终点和选中状态计算连续选择范围。
- 按原文相邻关系组合已选词块，连续中文不插入空格，其他词块使用可读空格分隔。

`ResourceEd2kImport` 继续保留现有公开方法以兼容资源导入代码，但其分词、连续选择和文本拼接改为调用通用模块。刮削管理直接调用通用模块，不依赖资源导入模块。

## 路径来源

- 单独选择一个文件夹时，使用该文件夹自身的完整路径。
- 选择一个或多个文件时，使用这些文件所在目录的完整路径。
- 选择多个文件夹，或文件与文件夹混合选择时，使用它们当前共同的父目录路径。
- 路径统一使用现有前端规范化格式；根目录没有可选路径文本时，显示明确的空状态，不用文件名或后端推荐词静默替代。

选词原文在打开识别面板时由当前有效选择计算并保存。选择发生变化后，现有识别上下文会被重置，下一次识别重新生成路径词块，避免沿用旧目录内容。

## 界面与状态

- 识别完成后，原候选关键词区域显示路径词块，默认不预选。
- 点击词块切换单个选中状态；按下后滑过多个词块可连续选中或取消。
- “完成选词”仅在已有选择时可用。点击后把组合文本写入 TMDB 搜索框，并将选词区收起为当前结果摘要。
- 摘要旁提供重新选词图标按钮。重新展开时保留上次词块选择，且不覆盖用户后来手工编辑过的搜索框内容，直到再次点击“完成选词”。
- TMDB 搜索框继续允许任意手工输入和修改；搜索、媒体类型选择及结果绑定行为不变。
- 后端 `/scraper/identify` 返回的 `keywords` 和 `query` 暂时保留，避免扩大接口变更范围；前端不再渲染旧的整段推荐关键词按钮，也不再用 `query` 自动填充搜索框。
- 识别中显示现有加载状态；路径为空时显示“当前选择没有可用的文件夹路径”，搜索框仍可手工输入。

## 响应式与主题

选词区位于识别摘要和 TMDB 搜索区之间，不新增二级弹窗或嵌套卡片。桌面端词块自然换行；移动端保持单列、词块可换行且容器不产生横向滚动。选中、未选中、禁用和焦点状态均覆盖现有日间与夜间主题。

## 验证

- 通用模块测试覆盖中英文路径分词、连续选中/取消和组合文本，并回归 ED2K 现有行为。
- 刮削前端测试覆盖单文件夹自身路径、多文件共同父目录、多文件夹/混合选择父目录、根目录空状态和完成选词填充逻辑。
- 模板测试确认旧关键词按钮被路径选词区替代，重新选词按钮具备可访问名称。
- 执行相关 unittest、完整 unittest、JavaScript 语法检查、Python `compileall` 和 `git diff --check`。
- 使用内置浏览器在桌面和 `390x844` 视口验证：路径词块内容、点击与滑动选择、完成后填入搜索框、重新展开保留选择、手工编辑不被意外覆盖、日夜主题可读性及无横向溢出。
